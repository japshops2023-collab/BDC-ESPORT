# BDC E-SPORT — เว็บไซต์ชุมนุมอีสปอร์ต

เว็บไซต์ชุมนุมอีสปอร์ตของโรงเรียนภาษาไทย ดีไซน์สไตล์อีสปอร์ต รองรับมือถือ
พร้อม **หน้าแอดมินที่แก้ไขเนื้อหาได้ทันทีจากในเว็บ** ไม่ต้องแก้โค้ด และระบบล็อกอิน
(รหัสผ่าน + Google Login แบบไม่บังคับ)

## ฟีเจอร์

**หน้าเว็บสาธารณะ**
- หน้าแรก: ฮีโร่ แมตช์ถัดไป สถิติ เกม ทีม ตารางแข่ง ข่าวสาร
- หน้าเกม / ทีม / นักกีฬา พร้อมรายละเอียดและรายชื่อผู้เล่น
- ตารางการแข่งขัน (กำลังจะมาถึง / ถ่ายทอดสด / จบแล้ว)
- ข่าวสารและหน้าบทความ
- หน้าเกี่ยวกับสมาคม และหน้าใบสมัครเข้าร่วม (ส่งเข้าถล่องข้อความแอดมิน)

**หน้าแอดมิน** — `http://localhost:3000/admin`
- แดชบอร์ดสรุปสถิติ แมตช์ ข่าว และข้อความใหม่
- เพิ่ม / แก้ไข / ลบ เกม, ทีม, นักกีฬา, แมตช์, ข่าวสาร
- อัปโหลดรูปภาพ (PNG, JPG, WebP, GIF ขนาดไม่เกิน 6 MB)
- กล่องข้อความใบสมัครจากหน้าเว็บ (อ่าน / ไม่ได้อ่าน / ลบ)
- ตั้งค่าเว็บไซต์: ชื่อเว็บ, ข้อความฮีโร่, สีหลัก, เกี่ยวกับสมาคม, ช่องทางติดต่อ, รูปภาพ, อีเมล Google ที่อนุญาต
- เปลี่ยนรหัสผ่าน และออกจากระบบ
- แก้ไขได้ทั้งคอมพิวเตอร์และมือถือ (เมนูด้านข้างแบบเลื่อน)

## เริ่มใช้งาน

1. ดับเบิลคลิก **`start.bat`**
   (ถ้ามี Node.js ในเครื่องอยู่แล้วสามารถใช้ `node server.js` หรือ `npm start` ได้)
2. เปิดเว็บ `http://localhost:3000`
3. เข้าหน้าแอดมิน `http://localhost:3000/admin`

ครั้งแรกที่รัน ระบบจะสร้างฐานข้อมูลตัวอย่าง (6 เกม, 13 ทีม, 51 นักกีฬา, 9 แมตช์, 3 ข่าว)

### รหัสผ่านแอดมินเริ่มต้น

`admin1234`

เข้าใช้งานด้วยการกรอกรหัสผ่านเท่านั้น (ไม่ต้องใช้อีเมล)

> แนะนำให้เปลี่ยนรหัสผ่านทันทีที่ **ตั้งค่าเว็บไซต์ → เปลี่ยนรหัสผ่าน**
> เมื่อเปลี่ยนแล้ว ระบบจะออกจากทุกเซสชันเดิมและให้เข้าสู่ระบบใหม่

## Google Login (ไม่บังคับ)

1. คัดลอก `.env.example` เป็น `.env` (ไฟล์ต้องอยู่โฟลเดอร์เดียวกับ `server.js`)
2. ไปที่ [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials)
   สร้าง **OAuth client ID** ชนิด **Web application**
3. ใส่ **Authorized redirect URI**
   - ในเครื่อง: `http://localhost:3000/auth/google/callback`
   - ออนไลน์: `https://โดเมนของคุณ/auth/google/callback`
4. ใส่ค่าใน `.env`
   ```
   GOOGLE_CLIENT_ID=...
   GOOGLE_CLIENT_SECRET=...
   # ถ้าใช้ออนไลน์และ redirect ไม่ตรงกับ localhost
   # GOOGLE_REDIRECT_URI=https://โดเมนของคุณ/auth/google/callback
   ```
5. อนุญาตอีเมลผู้ดูแล เพิ่มได้ 2 วิธี
   - ในหน้า **ตั้งค่าเว็บไซต์ → อีเมล Google ที่อนุญาต**
   - หรือใน `.env`: `ADMIN_EMAILS=you@gmail.com,another@gmail.com`
6. รีสตาร์ทเซิร์ฟเวอร์ ปุ่ม **เข้าสู่ระบบด้วย Google** จะแสดงในหน้าแอดมิน

อีเมลแอดมินหลัก (`adminEmail` ในหน้า settings) ได้รับอนุญาตอยู่แล้วโดยอัตโนมัติ

## ใช้งานในวง LAN

ค่าเริ่มต้นเซิร์ฟเวอร์เปิดที่ `0.0.0.0` พอร์ต `3000` เครื่องอื่นในวงเน็ตเวิร์กเดียวกันเปิดได้ที่
`http://<IP ของเครื่องนี้>:3000` (ต้องอนุญาตพอร์ต 3000 ในไฟร์วอลล์ของ Windows)

หากพอร์ตชนกับโปรแกรมอื่น ให้สร้าง `.env` แล้วกำหนด `PORT=3001` เป็นต้น

## โครงสร้างโปรเจกต์

```
server.js          เซิร์ฟเวอร์ HTTP และเส้นทางไฟล์/หน้าเว็บ
lib/
  api.js           REST API (สาธารณะ + แอดมิน), ตรวจสอบข้อมูล
  auth.js          ล็อกอินด้วยรหัสผ่าน, Google OAuth, เซสชัน
  passwords.js     แฮชรหัสผ่านด้วย scrypt
  store.js         ฐานข้อมูล JSON และข้อมูลตัวอย่าง
public/
  index.html       หน้าเว็บสาธารณะ
  admin.html       หน้าแอดมิน
  js/public.js     ตัวจัดการหน้าเว็บสาธารณะ
  js/admin.js      ตัวจัดการหน้าแอดมิน
  js/util.js       ฟังก์ชันกลาง (เรียก API, จัดรูปแบบวันที่, ธีม)
  css/             สไตล์ทั้งหมด + ฟอนต์ไทยในเครื่อง
  assets/          รูปฮีโร่และฟอนต์
data/db.json       ฐานข้อมูล (สร้างอัตโนมัติเมื่อรันครั้งแรก)
uploads/           รูปที่อัปโหลดจากหน้าแอดมิน
```

ไม่ต้องรัน `npm install` — โปรเจกต์ใช้ Node.js ล้วน ไม่มี dependencies ภายนอก
(ต้องใช้ Node.js 18 ขึ้นไป หรือใช้ Node ที่มาพร้อมใน `.runtime/` ผ่าน `start.bat`)

## สำรองข้อมูล / ย้ายเครื่อง

สำรองข้อมูลโดยคัดลอก 2 อย่างนี้
- `data/db.json` — เนื้อหาทั้งหมด การตั้งค่า และบัญชีแอดมิน
- `uploads/` — รูปภาพที่อัปโหลด

เมื่อย้ายเครื่อง ให้นำทั้งสองอย่างไปวางในโฟลเดอร์โปรเจกต์เดิม แล้วรัน `start.bat`

## หมายเหตุด้านความปลอดภัย

- หน้าแอดมินทุก API ต้องมีเซสชันที่ล็อกอินแล้ว และมีการตรวจ Origin + CSRF header
- จำกัดการลองล็อกอินผิด 10 ครั้งต่อ 10 นาทีต่อ IP
- เมื่อนำขึ้นออนไลน์จริง ควรใช้ HTTPS (คุกกี้จะถูกตั้งเป็น Secure อัตโนมัติเมื่ออยู่หลัง HTTPS)
- ไฟล์ `.env`, `data/db.json` และ `uploads/` ถูกกันไว้ใน `.gitignore` แล้ว
